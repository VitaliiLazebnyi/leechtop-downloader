# Requirements

## Active Specifications

- **LT-REQ-001 (Core Execution):** The CLI tool must be executable from the command line via the `leechtop` binary.
- **LT-REQ-002 (URL Acceptance):** The tool must accept one or more URLs as inputs for downloading.
- **LT-REQ-003 (Download Persistence):** The tool must stream the contents of the given URLs to the local filesystem reliably.
- **LT-REQ-004 (Metric Standard):** Any internal calculation of file size, bandwidth, or chunking must strictly utilize the Metric system (e.g., bytes, kilobytes, not binary kibibytes internally unless formatting for display explicitly requires it, but logic must be metric).
- **LT-REQ-005 (Temporal Standard):** All internal logs and file metadata timestamps generated by the tool must default strictly to UTC.
